  \item PDK / corner: sky130\_fd\_pr 1.8\,V nfet/pfet, \texttt{tt}
  \item Supplies / bias: $V_{DD}{=}\SI{1.8}{V}$, $I_{\mathrm{bias}}{=}\SI{20}{\micro A}$, $V_{\mathrm{CM}}{=}\SI{300}{mV}$ (design), $C_L{=}\SI{100}{pF}$
  \item Compensation: $C_0{=}\SI{11}{pF}$ (outer, \texttt{net063}$\to$\texttt{vout}), $C_1{=}\SI{0.35}{pF}$ (inner, \texttt{net050}$\to$\texttt{net013})

\paragraph{Topology.}
PMOS input pair (\texttt{xm8/xm9}, $g_{m1}$) with folded-cascode NMOS (\texttt{xm15/xm16} as $g_{mb}$ / current buffer) and PMOS mirror load (\texttt{xm5/xm6}) forms stage~1 (output \texttt{net050}).
Stage~2 is PMOS CS \texttt{xm10} ($g_{m2}$) loaded by NMOS current source \texttt{xm59} (output \texttt{net013}).
Stage~3 is PMOS CS \texttt{xm7} ($g_{m3}$) with NMOS mirror \texttt{xm21/xm22} to \texttt{vout}.
Feedforward PMOS \texttt{xm11} ($g_{mf}$) from \texttt{net050} to \texttt{vout}.
Outer compensation $C_0$ closes through the cascode buffer (RAFFC active outer loop); $C_1$ is the reversed nested inner Miller.

\section{Small-signal analysis}
Assumptions: strong-inversion square-law estimates, $\mu_p C_{\mathrm{ox}}\!\approx\!\SI{50}{\micro A/V^2}$, $\mu_n C_{\mathrm{ox}}\!\approx\!\SI{270}{\micro A/V^2}$, $V_{\mathrm{ov}}\!\approx\!\SI{0.2}{V}$ when used, parasitics neglected, devices in saturation (idealized---see sim).

\paragraph{Bias.}
Reference $I_0{=}\SI{20}{\micro A}$. Tail \texttt{xm4} has $M{=}2\Rightarrow I_{\mathrm{tail}}\!\approx\!\SI{40}{\micro A}$, so $I_{D1}{=}\SI{20}{\micro A}$ per input device.
\[
g_{m1}\approx\sqrt{2\mu_p C_{\mathrm{ox}}(W/L)I_{D1}}
=\sqrt{2\cdot 50\times10^{-6}\cdot 1\cdot 20\times10^{-6}}
\approx\SI{45}{\micro S}
\]
(alt.\ $g_{m1}{\approx}2I_D/V_{\mathrm{ov}}{\approx}\SI{200}{\micro S}$).

\paragraph{Gains / GBW (RAFFC).}
With outer capacitor $C_c{=}C_0$:
\[
\mathrm{GBW}\approx\frac{g_{m1}}{2\pi C_0}
\approx
\begin{cases}
\SI{0.65}{MHz}, & g_{m1}{=}\SI{45}{\micro S}\\
\SI{2.9}{MHz}, & g_{m1}{=}\SI{200}{\micro S}.
\end{cases}
\]
Three-stage DC gain (order-of-magnitude, $g_m r_o\!\sim\!20$--$40\,\mathrm{dB}$ per stage if saturated):
\[
A_0\approx A_1 A_2 A_3 \sim \SI{60}{dB}\text{--}\SI{100}{dB}.
\]
Phase margin: RAFFC places a LHP zero / buffered outer loop; with $C_1{\ll}C_0$ and adequate $g_{m2,3}$, target PM is typically $\sim\SI{60}{\degree}$ when sized---not computable reliably without valid OP $g_m$/$r_o$.

\paragraph{Power (order of magnitude).}
Branches at $\times1$--$\times8$ mirrors of $\SI{20}{\micro A}$ suggest $I_{DD}\!\sim\!\SI{0.2}{mA}$--$\SI{1}{mA}$ $\Rightarrow$ $P\!\sim\!\SI{0.4}{mW}$--$\SI{1.8}{mW}$ at \SI{1.8}{V}.

\section{Results}
\subsection{Operating point (open-loop diagnostic)}
At $V_{\mathrm{CM}}{=}\SI{0.9}{V}$: $V_{\mathrm{out}}{\approx}\SI{29}{mV}$ (railed low), $V(\texttt{net31}){\approx}\SI{1.799}{V}$ (PMOS tail $\approx$ shorted to $V_{DD}$), $V(\texttt{net013}){\approx}\SI{11}{mV}$, $V(\texttt{net050}){\approx}\SI{0.49}{V}$.

\paragraph{ADM Bode.} Magnitude stays near $-15\,\mathrm{dB}$ from \SI{0.1}{Hz} through midband, then falls to $\sim-100\,\mathrm{dB}$ by \SI{1}{GHz} (data: \texttt{figures/bode\_mag.dat}); DC phase $\approx 180^\circ$. No unity-gain frequency.

\section{Match assessment}
Match gates (DC gain $\pm3\,\mathrm{dB}$, GBW $\pm30\%$, PM $\pm10^\circ$): \textbf{all fail}.

Top causes:
\begin{enumerate}
  \item \textbf{Placeholder sizing.} AnalogGym variables set every $W{=}L{=}1$ (and modest $M$). This is an optimization seed, not a biased RAFFC design; stage currents / headroom collapse (see OP).
  \item \textbf{No unity-gain crossing.} With $|A_0|{\approx}-15\,\mathrm{dB}$, GBW and PM measures are undefined.
  \item \textbf{Hand analysis assumes saturation} that the stock netlist does not achieve; theory numbers are topology targets, not predictions of this OP.
\end{enumerate}

\paragraph{Recommendation.} Re-size (or load a sized solution) so that $g_{m1}$--$g_{m3}$ and cascode mirrors sit in saturation at $V_{\mathrm{CM}}{\approx}0.3$--$0.9\,\mathrm{V}$, then re-run this flow.
